맑은 고딕 9.5pt, 버튼 높이 34px, 기본 간격 8px를 공통 기준으로 사용합니다. 슬롯 이름처럼 길이가 가변인 내용은 말줄임으로 표시하며, 표의 긴 내용은 가로 스크롤로 읽을 수 있습니다. 편집창의 실행 경로와 클래스는 읽기 전용 입력칸에서 전체 값을 확인할 수 있습니다.

단축키 회귀 검사에서 키 전달은 합성 `WM_HOTKEY`, 버튼 실행은 `PerformClick`입니다. 실제 OS 키 입력 4회 검사는 [이전 v0.3.1 검증](검증-v0.3.1.md)에 기록되어 있으며 이번 화면 수정에서는 반복하지 않았습니다. 실제 창 이동은 PID와 생성 시각으로 소유권을 확인한 GUI 시험 창에 한정했습니다. 사용자 배치에는 적용 버튼이나 배치 단축키를 누르지 않았습니다.

PC 업데이트는 현재 선택된 배치와 키 설정을 유지하며 실행 파일·바탕화면 바로가기·기존 로그인 작업의 실행 경로만 교체했습니다. 등록된 로그인 작업을 실행해 트레이 시작을 확인했으며 실제 재부팅이나 로그오프는 하지 않았습니다.
