# 창자리 (WindowDock) 사용법

## 실행과 첫 배치 저장

1. [최신 릴리스](https://github.com/Choi-sungjin/WindowDock/releases/latest)의 Windows x64 ZIP을 압축 해제합니다.
2. `WindowLayoutManager.exe`를 실행합니다.
3. 저장할 프로그램 창들을 원하는 위치와 크기로 직접 배치합니다.
4. **현재 창에서 새로 저장**을 누릅니다.
5. 저장할 창들을 고르고 배치 이름을 입력합니다.

처음 사용하는 PC에는 저장된 배치가 없습니다. 다운로드에는 개인 배치가 포함되지 않으므로, 자신의 창으로 첫 배치를 등록하세요. 작업용·회의용 등 여러 이름으로 따로 저장할 수 있습니다.

이미 사용하던 PC에서 업데이트하거나 ZIP을 다시 내려받는 경우에는 AppData에 저장된 기존 배치와 감시 설정을 그대로 사용합니다. 새로 다운로드했다고 기존 배치를 초기화하지 않습니다.

## 배치 적용과 감시 시작

### 지금 창들을 저장 위치로 옮기기

왼쪽에서 배치를 선택한 뒤 **지금 적용 + 자동 배치 시작**을 누릅니다. 현재 열린 창 중 저장된 항목과 일치하는 창을 옮기고, 이후 새로 열리는 창도 감시합니다. 닫혀 있는 프로그램을 실행하지는 않습니다.

### 지금 창들은 그대로 두고 새 창만 감시하기

1. 왼쪽에서 저장된 배치를 선택합니다.
2. **활성 배치로 선택**을 누릅니다.
3. 위쪽의 **활성 배치** 이름을 확인합니다.
4. **자동 배치: 꺼짐**이면 **자동 배치 시작**을 누릅니다. **켜짐**이면 그대로 둡니다.

이 경로에서는 기존 창을 옮기지 않습니다. **지금 적용 + 자동 배치 시작**은 이미 열린 창도 옮기는 버튼이므로 목적에 맞게 선택하세요.

### 자동 배치가 켜진 뒤

- 이후 새로 열린 일치 창만 저장 위치로 한 번 배치합니다.
- 직접 옮기거나 크기를 바꾼 창은 그대로 둡니다.
- 창을 닫아도 다른 창이 그 빈자리를 채우지 않습니다.
- 이미 다른 창이 사용 중인 저장 자리는 유지합니다. 같은 프로그램의 추가 창이 무조건 그 자리를 차지하는 것은 아닙니다.
- 앱을 다시 실행하면 저장된 활성 배치와 감시 상태를 읽고, 시작할 때 이미 열린 창은 이동하지 않습니다.
- **자동 배치 일시정지** 상태도 저장됩니다. 다음 실행에서 자동으로 켜지지 않습니다.

## 같은 프로그램의 여러 창 구분하기

오른쪽에서 항목을 선택하고 **항목 편집(세부)**을 엽니다. **타이틀 포함**에 해당 창 제목에서 구별되는 문구를 넣습니다. 예를 들어 자료용 브라우저 창은 문서 이름의 고유한 부분으로 구분할 수 있습니다.

제목이 바뀌면 조건에 맞지 않을 수 있습니다. 조건에 맞는 창이 없거나 여러 후보를 확실히 구분할 수 없으면 임의로 이동하지 않습니다. **최근 적용/자동 배치 결과**에서 확인하고 조건을 수정하세요.

## 저장한 배치 수정하기

- **선택 배치 업데이트**: 현재 일치하는 창의 위치·크기를 반영합니다. 확인을 취소하거나 저장에 실패하면 기존 배치를 유지하며, 현재 닫혀 있는 항목도 보존합니다.
- **항목 편집(세부)**: 역할 이름, 제목 조건, 좌표·크기 등을 수정합니다.
- **항목 삭제**: 선택한 배치에서 해당 항목을 제거합니다. 프로그램 창 자체를 닫지는 않습니다.
- **이름 변경**: 배치 이름을 바꿉니다.
- **삭제**: 선택한 배치를 삭제합니다.

## 트레이 사용

메인 창의 닫기 버튼이나 **트레이로 숨기기**를 누르면 감시를 계속합니다.

- 아이콘 두 번 클릭 또는 **열기**: 관리 화면 열기
- **배치 적용 → 배치 이름**: 그 배치를 현재 창들에 적용하고 자동 배치 시작
- **자동 배치 일시정지 / 시작**: 감시 상태 전환
- **종료**: 앱과 감시 완전 종료

아이콘이 보이지 않으면 작업표시줄의 숨겨진 아이콘 영역을 확인하세요. 이미 실행 중이면 EXE를 다시 실행하는 대신 트레이에서 화면을 여세요.

## 로그인할 때 트레이에서 자동 실행

Windows **작업 스케줄러**에서 한 번 설정합니다. 기존에 `WindowLayoutManager` 자동 실행 작업이 등록되어 있다면 새로 만들지 말고 그 작업의 경로를 확인하거나 수정하세요.

1. 실행 파일을 계속 사용할 폴더에 둡니다.
2. 작업 스케줄러에서 **작업 만들기**를 엽니다.
3. 이름을 `WindowLayoutManager`로 정하고 현재 사용자 계정을 선택합니다.
4. **사용자가 로그온할 때만 실행**을 선택합니다. **가장 높은 수준의 권한으로 실행**은 선택하지 않습니다.
5. **트리거 → 새로 만들기 → 로그온할 때**에서 현재 사용자를 지정합니다.
6. **동작 → 새로 만들기 → 프로그램 시작**에 아래 값을 넣습니다.

| 필드 | 입력 |
| --- | --- |
| 프로그램/스크립트 | `WindowLayoutManager.exe`의 전체 경로 |
| 인수 추가 | `--start-in-tray` |
| 시작 위치 | EXE가 들어 있는 폴더 |

7. 노트북에서도 계속 감시하려면 **조건**의 AC 전원에서만 시작 및 배터리 전환 시 중지 옵션을 해제합니다.
8. **설정**에서 실행 시간이 길어지면 중지하는 옵션을 해제하고, 이미 실행 중이면 **새 인스턴스를 시작하지 않음**으로 정합니다.
9. 저장한 뒤 작업을 우클릭해 **실행**하고 트레이 아이콘을 확인합니다.

먼저 앱에서 원하는 활성 배치를 선택하고 자동 배치를 켜 두세요. 로그인 시에는 그 상태를 이어받습니다. 로그인할 때 이미 열린 창은 이동하지 않고, 감시가 시작된 뒤 새로 열린 일치 창을 배치합니다.

자동 실행을 끄려면 이 작업을 **사용 안 함**으로 설정합니다. EXE를 다른 폴더로 옮겼다면 작업의 실행 경로와 바로가기도 함께 바꿔야 합니다.

## 백업과 업데이트

Windows 탐색기 주소창에 `%APPDATA%\WindowLayoutManager`를 입력하면 저장 폴더가 열립니다.

```text
WindowLayoutManager/
  profiles/       이름별 배치 JSON
  settings.json   활성 배치와 감시 상태
```

백업하려면 트레이 메뉴에서 앱을 종료한 뒤 이 폴더 전체를 다른 곳에 복사하세요. 다른 PC에 복원할 때는 프로그램 설치 경로, 창 제목, 화면 환경이 달라 일부 항목이 맞지 않을 수 있습니다.

업데이트할 때도 먼저 앱을 종료하고 새 EXE로 교체합니다. 저장 폴더는 유지하세요. 실행 파일명과 저장 폴더명은 이전 **창 배치 매니저**와의 호환성을 위해 `WindowLayoutManager`로 유지합니다.

## 창이 원하는 대로 배치되지 않을 때

1. **활성 배치** 이름과 **자동 배치: 켜짐**을 확인합니다.
2. **타이틀 포함** 조건이 실제 창 제목과 일치하는지 확인합니다.
3. 결과 목록에서 누락·모호함·이동 거부 여부를 확인합니다.
4. 앱이 허용하는 최소 크기 때문에 요청한 크기가 그대로 적용되지 않을 수 있습니다.
5. 관리자 권한 프로그램 등 일부 창은 Windows 권한 제한으로 제어되지 않을 수 있습니다.

다중 모니터·혼합 DPI·관리자 앱에 대한 실제 검증 범위는 [검증 문서](검증.md)를 확인하세요.
