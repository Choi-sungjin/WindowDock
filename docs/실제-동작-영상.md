## 촬영 범위

- 실제 앱의 `MainForm`, `MonitoringService`, Windows 창 이동 엔진을 촬영했습니다. 그림으로 만든 UI 애니메이션이 아닙니다.
- 촬영용 호스트에서 별도 저장 공간과 직접 만든 시험 창 3개를 사용했습니다. 이 호스트는 자신이 만든 프로세스의 ID와 생성 시각을 확인한 창만 앱에 전달합니다.
- 일상 작업 창, 개인 배치 파일, 계정 정보, 개발 세션 대화는 영상과 저장소에 포함하지 않습니다.
- 배치 A는 메신저가 오른쪽, 배치 B는 왼쪽인 예시입니다. 새로 내려받는 앱에는 이 시험 배치를 기본값으로 넣지 않습니다.
- 배치 B를 활성화한 뒤에도 기존 메신저 위치는 유지됩니다. 메신저를 직접 닫고 다시 열어 새 창 자동 배치를 확인했습니다.
- 내레이션은 수퍼톤의 로컬 **Supertonic 3**, 한국어 M1 음성입니다. Remotion으로 편집했습니다.
- 대기 구간을 줄이고, 촬영 테두리와 컴퓨터 조작 포인터 강조를 제거했습니다. 포인터 제거에는 같은 시험 창의 깨끗한 화면을 사용했습니다. 창 위치와 실제 앱 상태 변화는 녹화 내용입니다.

이 영상은 한 물리 화면에서 확인한 기본 흐름입니다. 다중 모니터, 관리자 권한 앱, 앱마다 다른 창 제목 및 보안 제약의 전체 검증을 의미하지 않습니다. 자세한 범위는 [검증 문서](검증.md)를 참고하세요.
