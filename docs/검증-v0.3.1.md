단축키 회귀 명령의 합성 `WM_HOTKEY` 전달과 실제 OS 키 입력을 구분했습니다. 실제 키 입력 검사는 최종 제품 어셈블리를 참조하는 독립 호스트와 직접 생성한 시험 창 하나를 사용했습니다. PID와 프로세스 생성 시각이 맞는 시험 창만 이동했고 소유 범위 위반은 0건입니다. 사용자 배치에 적용 버튼이나 배치 단축키를 누르지 않았습니다.

최종 PC의 관리 화면과 단축키 설정 창에서 새 아이콘, 8개 슬롯과 이전·다음의 키 설정 항목을 확인했습니다. 바탕화면 바로가기에서 추출한 아이콘도 직접 확인했습니다. 기존 키 설정을 임의로 켜거나 바꾸지 않았습니다.

## 확인하지 않은 범위

실제 재부팅·로그오프는 하지 않았으며 등록된 로그인 작업을 직접 실행했습니다. 물리 화면 1대(5120×1440)에서 검사했고 여러 물리 모니터·혼합 DPI·관리자 권한 앱은 이번 수정에서 재검증하지 않았습니다. Linux 소스와 버전은 변경하지 않았습니다.

## 새 검사 명령

이전 [검사 명령](검증.md#검사-명령)에 더해, 게시된 EXE로 아래 명령을 실행할 수 있습니다.

```powershell
.\WindowLayoutManager.exe --activation-smoke --output .\activation.json
```

이 명령은 고유한 시험용 이벤트 이름과 임시 데이터를 사용합니다. 실행 중인 일상 앱에 신호를 보내거나 사용자 창을 옮기지 않습니다.
