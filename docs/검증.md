## 응답 없음 수정

앱 내부의 다른 스레드가 만든 숨은 창의 제목을 읽을 때 UI 스레드가 서로 기다릴 수 있었습니다. 자기 프로세스의 창은 제목 조회 전에 제외하도록 수정했습니다. 동일 조건의 독립 재현에서 구버전은 3,555ms, 수정본은 34ms에 열거를 마쳤습니다.

다른 프로세스의 멈춘 시험 창은 계속 목록에서 읽을 수 있습니다. 3.5초 동안 응답하지 않는 자체 시험 창을 만든 뒤, 일반 열거 12ms·메타데이터 열거 14ms를 확인했습니다. 일상 실행 파일 교체 후에도 앱 소유 창 10개의 응답 검사를 통과했습니다.

## 단축키 검증의 구분

- `--hotkey-smoke`는 실제 WinForms와 전역 키 등록을 사용하지만 창 제공자는 메모리 모델입니다. 15단계 중 단축키 전달은 합성 `WM_HOTKEY`, 버튼은 `PerformClick`입니다. 이를 실제 키보드 입력 증거로 세지 않았습니다.
- 별도 독립 호스트에서는 실제 MainForm과 Windows 창 이동 엔진을 사용했습니다. OS 키 입력으로 슬롯 1·8, 다음·이전 배치가 각각 자체 시험 창을 옮겼고, 메인 창은 숨겨진 상태였습니다. 4회 이동 모두 정확한 좌표이며 소유 범위 위반은 0건입니다.
- 실제 설정 창에서 이미 등록된 키를 입력 칸으로 전달하고, 취소하면 기존 설정과 창 위치를 유지하는 것을 확인했습니다. 새 키 조합 `Ctrl+Alt+Shift+F11` 입력·확인도 독립 UI 호스트에서 확인했습니다.
- 중복 키, Windows/F12 키, 잘못된 JSON 및 중복 속성, 실제 파일 잠금 저장 실패, 실제 `RegisterHotKey` 충돌과 해제를 별도로 검사했습니다. 저장 실패 시 기존 파일·메모리 설정·키 등록이 유지됐습니다.
- 확인·편집 창이 열렸을 때 단축키를 무시하고 뒤늦게 실행하지 않는 점, 기본·최소 크기에서 설정 행의 정렬을 검사했습니다.

GUI 및 실제 창 검사에서는 자체 생성하고 PID와 프로세스 생성 시각을 확인한 시험 창만 이동·종료했습니다. 설정 변경과 앱 시작만으로 배치를 적용하지 않습니다. 운영 PC의 저장 파일은 업데이트 전후 해시가 같았고 로그인 작업과 바로가기는 새 실행 파일을 가리킵니다.

개인 경로와 창 제목을 제외한 결과는 [verification-v0.2.0.json](verification-v0.2.0.json), 이전 결과는 [v0.1.0 검증](검증-v0.1.0.md)에 있습니다.

## 확인하지 못한 범위

- 실제 PC 재부팅·로그오프는 수행하지 않았습니다. 등록된 로그인 명령을 직접 실행했습니다.
- 물리 화면 1대, 5120×1440에서 검증했습니다. 여러 물리 모니터·혼합 DPI와 관리자 권한 앱은 별도 검증이 필요합니다.
- Windows의 전면 전환 제한으로 다른 시험 창을 전면에 유지하는 관찰 1건은 성립하지 않았습니다. 최대화 기능은 별도로 통과했으며, 성립하지 않은 관찰을 통과 수에 넣지 않았습니다.
- 모든 프로그램의 창 제목·보안 제약에 대한 호환성을 보장하는 결과는 아닙니다.

## 검사 명령

Windows의 대화형 데스크톱에서 아래 명령을 **순서대로** 실행하세요. GUI·native 검사는 시험 창을 잠시 열고 움직입니다. 출력에는 시스템 경로 등이 들어갈 수 있으므로 공유 전에 확인하세요.

```powershell
$exe = (Resolve-Path .\WindowLayoutManager.exe).Path
$checks = Join-Path (Get-Location) ('checks-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
New-Item -ItemType Directory -Path $checks | Out-Null

foreach ($mode in 'self-test','hotkey-smoke','tray-start-smoke') {
  $output = Join-Path $checks ($mode + '.json')
  $p = Start-Process $exe -WindowStyle Hidden -Wait -PassThru -ArgumentList @(
    ('--' + $mode), '--output', ('"' + $output + '"')
  )
  if ($p.ExitCode -ne 0) { throw "$mode failed" }
}

$p = Start-Process $exe -WindowStyle Hidden -Wait -PassThru -ArgumentList @(
  '--ui-smoke', ('"' + (Join-Path $checks 'ui.png') + '"'),
  '--data-dir', ('"' + (Join-Path $checks 'ui-data') + '"'),
  '--output', ('"' + (Join-Path $checks 'ui.json') + '"')
)
if ($p.ExitCode -ne 0) { throw 'UI smoke failed' }

$p = Start-Process $exe -WindowStyle Hidden -Wait -PassThru -ArgumentList @(
  '--native-smoke', '--data-dir', ('"' + (Join-Path $checks 'native-data') + '"'),
  '--output', ('"' + (Join-Path $checks 'native.json') + '"')
)
if ($p.ExitCode -ne 0) { throw 'Native smoke failed' }
```
